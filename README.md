# LmArena

## Лабораторные работы по защите информации

| № | Тема | Каталог | Запуск |
|---|------|---------|--------|
| 12 | **Ментальный покер** — Техасский холдем без доверенного дилера (протокол Shamir–Rivest–Adleman, коммутативное шифрование, совместное вскрытие карт), GUI, 2–6 игроков, колода 36/52 | [`lab12_mental_poker/`](lab12_mental_poker/) | `python3 lab12_mental_poker/server.py` → http://127.0.0.1:8012 |
| 13 | **Слепая подпись** — анонимное голосование (Да / Нет / Воздержался) по схеме Чаума на RSA, раздельные клиентская и серверная части, вывод всех чисел протокола | [`lab13_blind_signature/`](lab13_blind_signature/) | `python3 lab13_blind_signature/server.py` → http://127.0.0.1:8013 |

Обе лабораторные написаны на **чистом Python 3** без внешних зависимостей
(веб-интерфейс на `http.server` + ванильный JS), запускаются одной командой
и не требуют установки пакетов. Тесты: `python3 test_lab12.py` / `python3 test_lab13.py`
в каталоге каждой лабораторной. Подробности и обоснования схем — в README внутри каталогов.
