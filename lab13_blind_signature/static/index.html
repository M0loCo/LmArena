    ИТОГИ

    Результаты голосования

    Почему сервер не может подделать или связать голоса?
    Подпись выдаётся только под ослеплённым значением m′ = H·re mod n, где r знает лишь избиратель. Значения (m′, s′) из журнала выдачи и (M, s) из урны не связывает ни одно публичное число: s = s′·r−1 mod n «переносит» подпись на исходное сообщение. Проверка любого бюллетеня (se mod n = SHA-256(M)) — публична, но принадлежность бюллетеня конкретному избирателю — нет. Повторное голосование исключено реестром выдач; дубликат бюллетеня отсеивается по id при вбросе.
