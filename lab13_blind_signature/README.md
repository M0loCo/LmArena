# Лабораторная работа №13 — «Слепая подпись» на базе системы анонимного голосования

Реализация **слепой цифровой подписи Чаума (David Chaum, 1982)** на базе RSA.
Голосование по одному вопросу с вариантами **{Да, Нет, Воздержался}**.
Программа разделена на две логические части — **клиентскую** (избиратель)
и **серверную** (избирательная комиссия) — и показывает все числа протокола.

## Быстрый запуск

Требуется только **Python 3.8+** (стандартная библиотека, без pip-зависимостей):

```bash
python3 server.py            # http://127.0.0.1:8013
python3 server.py --port 9000
```

При старте автоматически генерируются RSA-1024 ключи комиссии и три избирателя:
Алиса, Боб, Чарли (можно добавить своих). Открыть: <http://127.0.0.1:8013>

## Протокол (5 шагов в интерфейсе)

```
Сервер:  (n, e, d) — RSA; регистрирует избирателя, выдаёт РОВНО ОДНУ подпись на имя.

Клиент:  1) Бюллетень  M = "BLIND-BALLOT-v1|id=<12 hex>|choice=<Да|Нет|Воздержался>"
                       H = SHA-256(M) как целое число
         2) Ослепление r ← случайное, НОД(r, n) = 1
                       m′ = H · r^e mod n
         3) Сервер (НЕ ВИДЯ M и H):  s′ = m′^d mod n        — «слепое подписание»
         4) Клиент:    s = s′ · r^(−1) mod n
                       проверка: s^e mod n == H  ✓
         5) Анонимный канал: клиент кладёт в урну (M, s), сервер проверяет подпись
            и принимает бюллетень. Id бюллетеня защищает от дублей.
```

Почему это работает: `s^e ≡ (m′^d)^e · r^(−e) ≡ H·r^e · r^(−e) ≡ H (mod n)`.

## Защищённость и анонимность (что говорить на защите)

* **Слепота (blinding).** Сервер при подписании видит только `m′ = H·r^e mod n`.
  Так как `r^e mod n` равномерно распределено в Z*_n (e взаимно просто с φ(n)),
  `m′` не раскрывает `H` и уж тем более выбор избирателя. Подписывать «что попало»
  сервер не может — домен-сепарация: в подписываемое сообщение вшит тег
  `BLIND-BALLOT-v1`, и сервер принимает в урну только бюллетени строго такого формата.
* **Неотслеживаемость (unlinkability).** В журнале выдачи хранятся `(m′, s′)`,
  в урне — `(M, s)`. Единственное связующее звено — секретный `r`, который знает
  только клиент и который никуда не передаётся. Сервер, глядя на урну, не может
  сказать, кто каким бюллетенем голосовал, даже расплачиваясь своими записями.
* **Одно голосование на избирателя.** Выдача подписи отмечается в реестре;
  повторный запрос того же избирателя отклоняется (`«уже получил подпись»`).
  Дубль бюллетеня в урне отсекается по `id`.
* **Целостность и недопустимость подделки.** Поменять выбор в бюллетене нельзя:
  подпись проверяется как `s^e mod n == SHA-256(M)`; подмена `choice` ломает
  равенство (см. тест `test_tampered_rejected`).
* **Публичная проверяемость.** Любой наблюдатель может пересчитать `H` из `M`
  и проверить `s^e mod n == H` для каждого бюллетеня в урне (кнопка
  «Проверить все подписи в урне»).
* **Доверие к подсчёту.** Все голоса в урне валидны по подписи ⇒ посчитать
  результаты может любой участник локально.

### Ограничения и допущения (честно)
* Один секретный ключ сервера — точка отказа; в боевых системах ключ держат
  порогово и добавляют микс-сети (mix-nets) для стойкости к активному серверу.
* Сервер может отказать конкретному избирателю в выдаче (отказ в обслуживании),
  но не может узнать его выбор и не может подменить результат незамеченным образом
  (подписанный бюллетень нельзя сфабриковать без d).
* Слепая подпись сама по себе не даёт «receipt-freeness» (принуждение избирателя
  показать r) — в реальных выборах это решается специальными протоколами (receipt-free, крепостные коды); для учебной
  модели достаточно разделения секретов клиента.
* RSA-1024 — минимальный учебный размер; на практике от 2048 бит.

## Что показать на защите (сценарий демо)

1. **«Клиент»**: выбрать избирателя → «1. Сформировать бюллетень» — видны `M` и `H`.
2. «2. Ослепить» — виден секретный `r` и ослеплённое `m′` (это всё, что увидит сервер).
3. «3. Получить подпись сервера» — серверная колонка: m′ попадает в журнал выдачи,
   реестр отмечает «подпись выдана».
4. «4. Снять ослепление» — клиент локально проверяет `s^e mod n == H`.
5. «5. Отправить в урну» — бюллетень появляется в урне **без имени избирателя**.
6. **«✔ Проверить все подписи»** — все бюллетени валидны.
7. Попытка проголосовать тем же избирателем ещё раз → шаги 1–3 отклоняются сервером.
8. Итоги (Да/Нет/Воздержался, явка) обновляются автоматически.
