# cmpl — лабораторные работы по компиляторам (compilers-fall, лекции 1–4)

Четыре связанные работы: это единый путь от сборки LLVM/clang до собственного
компилятора маленького языка (TinyLang, диалект Modula-2) с генерацией кода в LLVM IR.

```
Лаб.1  clang/LLVM из исходников, пример 07-calc (лексер → парсер → AST → семантика → IR)
  │        └─ «калькулятор»: разбор выражения, типобезопасная (пока константная) семантика
  ▼
Лаб.2  Tinylang: лексический и синтаксический анализ, семантический анализ,
  │        области видимости, типы, диагностика (линтер фронтенда)
  ▼
Лаб.3  LLVM IR: ручная реализация НОД в LLVM IR, разбор трансляции аргументов и циклов
  │
  ▼
Лаб.4  Tinylang → LLVM IR: кодогенерация (SSA, phi-функции), BOOLEAN → i1
```

Все работы выполнены в ветке и могут быть проверены независимо:

| Папка | Что сделано | Отчёт |
|-------|-------------|-------|
| `compilers-fall-lec1/` | **справочно / оставлено как было**: первая лаба есть у пользователя в готовом виде и является приоритетной; здесь — починенные скрипты `00-build-llvm`, правка 07-calc (проверка деления на 0), AST-диаграмма | `lab1/LAB1.md` |
| `compilers-fall-lec2/` | сборка Tinylang; прогнаны тесты по `lab2-tasks.txt` (сложение числа и строки, while INTEGER, RETURN в процедуре, scope, дубликаты параметров); ответы по коду компилятора | `lab2/LAB2.md`, тесты в `lab/tests/` |
| `compilers-fall-lec3/` | `gcd.c` → `gcd.ll` (ручной, рядом с `gcd.c`); сравнение с ИР от clang -O0/-O1; объяснение трансляции аргументов и цикла. **Запуск через lli/clang выполняет пользователь** — см. `LAB34-INSTRUCTIONS.md` | `gcd.ll` + `lab3/LAB3.md` |
| `compilers-fall-lec4/` | разбор кодогенератора (базовые блоки if/while, SSA, phi); поддержка BOOLEAN → i1 в генераторе кода (патч применён); тесты `boolean-*.mod`. **Сборка и эмиссия IR против LLVM пользователя** — см. `LAB34-INSTRUCTIONS.md` | `lab4/LAB4.md`, тесты в `lab/tests/` |

Требования: только LLVM 17 (сборка описана в `compilers-fall-lec1/00-build-llvm/README.md`),
CMake ≥ 3.20, Ninja, C++17-совместимый компилятор (gcc 12). Внешние зависимости не нужны.

## Сборка LLVM (для самопроверки)

Сборка clang из исходников в этой ветке **не доводилась до конца намеренно**:
первая лаба уже сделана на машине пользователя. Вся проверка через LLVM
(лабораторные 3 и 4) выполняется на машине пользователя по
`LAB34-INSTRUCTIONS.md`. Комментариев в кодовых файлах нет осознанно.
